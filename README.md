# La Peace Pricing

Webowa wycena zleceń Minecraft Java 1.21.11.

Funkcje:
- wyszukiwanie przedmiotów z bazy 1.21.11,
- obsługa Sculk i rodziny sculk,
- możliwość dodania własnego przedmiotu, jeśli nie zostanie wybrany z listy,
- stacki i sztuki,
- cena za sztukę i suma,
- biblioteka zapisanych cen z edycją i usuwaniem,
- zapis danych lokalnie w przeglądarce,
- PWA i cache offline po pierwszym uruchomieniu.

GitHub Pages jest wdrażane automatycznie przez workflow z katalogu `.github/workflows/pages.yml`.
